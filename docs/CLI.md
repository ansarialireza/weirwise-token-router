# CLI Operations Guide (`wtr`)

The lightweight `wtr` CLI allows developers and automation scripts to interact with Token Router from the terminal.

## Commands
- `wtr status`: Probe health and readiness.
- `wtr discover`: Discover capabilities, providers, and models.
- `wtr diagnostics`: Run automated infrastructure self-checks.
- `wtr chat <message> --provider <provider> --model <model>`: Test routed completion.
